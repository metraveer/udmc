# Частые вопросы

## Ключи случайные? У каждого игрока свой токен?

Административный токен содержит 32 случайных байта (256 бит). Пара Ed25519 и токен создаются системным криптографическим генератором. Совпадение независимо созданных ключей практически невероятно, но математически нулевую вероятность обещать нельзя.

Ключи подписи и ключ доступа относятся к проекту, не к каждому игроку, и живут на сервере. Панель получает ключ доступа при привязке. При переносе панели на другую машину привяжитесь заново или восстановите проект из резервной копии. Для друга используйте приглашение: каждый компьютер получает отдельный случайный ключ доступа с возможностью отзыва. [Несколько администраторов](administrators.md).

Игроки получают общий публичный ключ проверки подписи, не токен администратора. Публичный ключ не является секретом. Файлы сборки публичны по URL; отдельной авторизации каждого скачивающего игрока сейчас нет. HTTPS шифрует передачу, Ed25519 и SHA-256 проверяют подлинность и целостность.

## Можно установить первый агент кнопкой внутри обычного Minecraft?

Без уже установленного клиентского кода сервер не может записать JAR в папку `mods`, добавить исполняемый мод или открыть собственный установщик внутри игры. Загрузка серверного ресурспака не предоставляет права устанавливать код.

Безопасные варианты: один раз положить файл мода в профиль Fabric или NeoForge; использовать функцию установки сборки существующего игрового лаунчера; либо в будущем сделать отдельный установщик с явным выбором профиля. Последние два варианта не реализованы в UDMC и не означают, что сервер может сам установить мод.

Проверка при входе есть: сервер спрашивает клиента в фазе подключения и, если правило включено, объясняет отказ прямо на экране, с адресом страницы установки. Уже установленный мод знает папку игры через загрузчик и показывает синхронизацию, конфликты и предложение перезапуска в самой игре.

## Почему нельзя оставить любой мод с такой же версией?

Два разных JAR могут объявлять одинаковую версию, но содержать другой код. Поэтому автоматически переиспользуется только файл с точным SHA-256 из подписанной сборки. Другой JAR с тем же ID требует решения пользователя. UDMC не может доказать, что произвольная более новая версия совместима с сервером.

Перед публикацией проверяются объявленные зависимости и `breaks`, но не поведение кода модов. Удаление мода с блоками или измерениями может повредить мир даже при корректных метаданных. Сохраняйте резервные копии.

## Какой адрес вводить?

- `sync.example.com`: HTTPS через уже настроенный прокси, стандартный внешний порт 443.
- `https://sync.example.com:8443`: HTTPS на нестандартном внешнем порту, внутренний порт UDMC по умолчанию 3077.
- `192.168.1.50:3077` или `sync.example.com:3077`: прямой HTTP, только для доверенной сети с явным разрешением.
- `http://127.0.0.1:3077`: панель и сервер на одном компьютере. Другим игрокам нужен доступный им адрес, не localhost.

Порт входа в Minecraft и порт RCON не являются портами UDMC. Папку установленного Minecraft панель не ищет: агент запускается загрузчиком в правильном профиле. Для сервера дома настройка сети зависит от роутера, провайдера, VPN и хостинга; приложение не может автоматически устранить CGNAT.

## Нужно регистрироваться в Modrinth или CurseForge?

Нет. Modrinth и GitHub Releases работают без ключей и без аккаунта; для CurseForge нужен ваш личный бесплатный ключ API — он хранится в Windows Credential Manager и отправляется только CurseForge. Каталог ищет моды и подбирает обязательные зависимости; миры, готовые модпаки, личные коллекции и фоновое автообновление он не трогает. Загрузки проверяются: Modrinth — по размеру и SHA-512, CurseForge — по размеру и SHA-1. [Документация Modrinth](https://docs.modrinth.com/api/).

При открытии каталога сразу загружаются популярные моды. Minecraft-клиент не нужен. Даже без подключения к серверному агенту можно выбрать версию игры, искать и просматривать зависимости; добавить в черновик можно только при подключённом сервере.

## Зачем адрес UDMC и игровой адрес?

Название на странице **Сборка** предназначено людям, его можно менять. Постоянный ID проекта создаётся на сервере и связывает проект, его ключи и состояние клиентов; в панели его нет и менять его не требуется.

Адрес UDMC вводится один раз в **Настройка сервера → Подключение**: по нему панель говорит с сервером, и его же сервер запоминает при привязке, чтобы называть игрокам, откуда брать сборку. Игровой адрес в разделе **«Агенты и игроки»** — то, куда клиент предлагает игроку зайти после синхронизации. Порт и адрес прослушивания самого API (`apiPort`, `apiHost`) живут в `config/udmc-sync.json` на сервере; клиент узнаёт их от сервера при входе. За HTTPS-прокси или NAT внешний порт может отличаться от внутреннего: например, `443` снаружи и `3077` внутри.

## Почему адрес UDMC и подключение RCON нельзя просто напечатать?

Это защита от случайного изменения. Нажмите карандаш внутри самого поля: значения меняются в отдельном окне, где есть предупреждение и кнопка **Применить**. **Отмена** или Escape сохраняют прежние значения. После перезапуска поля снова показывают значение и не принимают ввод.

Чтобы переименовать сборку, измените название на странице **Сборка**. Отдельный проект — это отдельный сервер: он заведёт себе свой ID и свои ключи при первом запуске. Блокировка ввода не заменяет авторизацию, защиту Windows и резервные копии.

## Как меняется версия приложения?

Обычный выпуск повышает последнее число (`0.27.0 → 0.27.1`); новые возможности или изменившиеся агенты поднимают среднее (`0.27.1 → 0.28.0`). Номер приложения, номер агента и номер опубликованной сборки модов не следует путать: версия сборки модов меняется при публикации.

Новый установщик получает новую версию автоматически в процессе выпуска. Уже установленный Control проверяет обновления при запуске и ставит их одной кнопкой: он скачивает пакет, устанавливает его и перезапускается сам. Пакет без действительной подписи приложение не примет, переход на более старую версию запрещён.

Обновление ставится поверх прежней установки одним мастером, без отдельного деинсталлятора. Закройте Control перед обновлением. Сохранённые настройки и ключи остаются на месте.
