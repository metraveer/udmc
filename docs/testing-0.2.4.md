# Проверка UDMC 0.2.4

Дата: 27 августа 2026. Локальная проверка Windows и изолированных временных данных. Это не сертификация совместимости произвольной сборки Minecraft.

Установщик: `UDMC Control_0.2.4_x64-setup.exe`, 3 103 229 байт. Версии Windows-бинарника и установщика: `0.2.4`. SHA-256:

```text
610c299f6e3f007543f33464da2750ab48cab694e10b437131a6f3c209f5bceb
```

Путь после сборки: `apps/admin-desktop/src-tauri/target/release/bundle/nsis/`. Полная команда `npm run release:build -- --retry` успешно завершила все проверки и выпуск NSIS без дополнительного повышения версии.

## Автоматические проверки

| Проверка | Результат |
| --- | --- |
| `npm test` | 55 тестов: архивы, пути, зависимости Modrinth, доступ, настройки, DOM панели, ошибки HTTP |
| `npm run smoke` | Пройден HTTP-цикл отдельного Node API-mock |
| `cargo test` | 17 локальных тестов; сетевой тест по умолчанию пропускается |
| `live_catalog_download --ignored` | Отдельно пройден настоящий API/CDN Modrinth, Fabric API 0.158.0+26.2, 2 535 765 байт, проверка хеша; код мода не запускается |
| `cargo fmt --check`, `cargo clippy --all-targets -- -D warnings` | Пройдены |
| `npm run minecraft:build` | Пять Java-наборов на каждом Fabric-профиле: 1.21.1, 26.1.2, 26.2 |
| `npm run admin:test:instance` | Второй запуск и три серии по восемь запусков оставляют один процесс; аварийное завершение освобождает блокировку |

Java-наборы: `storeTest`, `securityTest`, `modCheckTest`, `accessTest`, `httpTest`. Проверяются публикация, откат после ошибки записи, подпись, повтор старого manifest, конфликты и личные моды, права администраторов и полный HTTP-цикл установки/удаления клиентских файлов. Файл 96 МиБ успешно передаётся при лимите Java heap 64 МиБ. На время тестов поднимаются только временные loopback-серверы.

Регрессионные тесты воспроизвели и закрыли: два окна при одновременном старте, остатки файлов/команд старого сервера и повторное включение кнопок питания после потери связи. RCON проверяется локальным TCP-стендом, включая задержку между частями ответа свыше прежнего порога 180 мс.

## Windows-окно

В изолированном debug-профиле проверены окно 940 x 660, неподвижный сайдбар при прокрутке, настоящий каталог Modrinth со значками, сворачивание и восстановление существующего окна повторным запуском, обычное закрытие. Рабочее приложение и его ключи не использовались. Тестовые процессы закрыты.

## Что ещё требует игрового стенда

- Запуск выделенного Minecraft-сервера и клиента на каждой версии с реальными сторонними модами, проверка mixin и игровых экранов.
- Замена занятых Windows JAR при запущенной игре, перезапуск через конкретный хостинг/supervisor и восстановление после отключения питания.
- Нагрузочные испытания множества игроков и работа через реальные VPN, прокси и ограничения провайдера.
- Повторная установка/обновление через графический NSIS-мастер на чистой Windows; автоматическая проверка шаблона не заменяет этот сценарий.

Перед использованием на основном сервере сделайте резервную копию мира. Подпись и проверка Fabric-метаданных защищают конкретные операции, но не доказывают безопасность кода модов и не гарантируют сохранность мира.
