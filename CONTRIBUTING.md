# Участие в разработке

Спасибо за интерес к UDMC Sync.

## Разработка с участием искусственного интеллекта

Значительная часть кода, тестов и документации проекта написана ИИ-ассистентами под управлением и с проверкой человека. Присылать правки, сделанные с помощью ИИ, можно и нужно — но действуют те же требования, что и к любому другому вкладу: вы отвечаете за код, который отправляете, проверяете его локально и способны объяснить, как он работает. Сгенерированный текст без проверки не принимается.

Перед изменениями создайте issue с описанием проблемы или предлагаемого поведения. Для небольших исправлений документации issue не обязателен.

## Локальная проверка

```powershell
npm ci
npm run smoke
npm run minecraft:build
npm run admin:build
```

Pull request должен:

- решать одну понятную задачу;
- не включать собранные `target/`, `build/`, `data/` и `.gradle/`;
- сохранять совместимость manifest schema либо явно повышать `schemaVersion`;
- добавлять проверку для изменений API или синхронизации;
- обновлять документацию при изменении установки или конфигурации.

Не добавляйте в репозиторий настоящие admin-токены, IP-адреса частных серверов, коммерческие моды или файлы, распространение которых запрещено их лицензией.

Открытая лицензия проекта пока не выбрана. До появления `LICENSE` отправка pull request не меняет правовой статус репозитория.
