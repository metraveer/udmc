Что означает «Под управление»?

Эти файлы лежат на сервере, но не входят в сборку: UDMC их не обновляет, не раздаёт игрокам и не учитывает при проверках. «Под управление» добавляет файл в черновик с выбранным назначением - после публикации он станет частью сборки. Удаление на этой вкладке касается только файла на сервере, применяется после публикации и сохраняет резервную копию; личные моды игроков не затрагиваются.

Автоматически

Совместимость модов

Проверка запускается сама: при каждом изменении черновика и после каждой публикации. Результат для черновика также виден в его строке, для сервера - на странице «Сервер».

Что проверяется?

Обязательные зависимости, версии, дубликаты и назначение из метаданных JAR. Черновик проверяется для сервера и клиентов. Личные моды игроков проверяются их агентом при запуске. Проверка не гарантирует совместимость мира: перед изменением модов нужна его резервная копия.

Чем отличается от Modrinth?

Только опубликованные JAR из публичного репозитория автора. У GitHub нет общего списка версий Minecraft и графа зависимостей: они проверяются по JAR перед публикацией сборки. Публичный репозиторий сам по себе не даёт права раздавать файлы: проверьте лицензию выбранного мода. Частные репозитории, исполняемые установщики и архивы сборок не поддерживаются.

Описание релиза

Каталог CurseForge

CurseForge выдаёт данные только по личному ключу API. Создайте бесплатный ключ в консоли CurseForge for Studios и сохраните его здесь: он попадёт в защищённое хранилище Windows этого профиля и не покидает ваш компьютер.

Зачем нужен ключ?

Нужен ключ организации Core API: зарегистрируйтесь на console.curseforge.com, создайте организацию и скопируйте ключ со страницы «API keys» (вид $2a$10$...). Свежий ключ может активироваться несколько минут. Не подходят: UUID-токены со старого сайта авторов legacy.curseforge.com («My API Tokens» — это загрузка своих модов) и персональный Profile API key (cfc_pat_...) из раздела Profile консоли. Ключ бесплатный; UDMC использует его только для поиска и загрузки модов, авторы которых разрешили раздачу через API.

Чем отличается от Modrinth?

Показываются только моды, авторы которых разрешили раздачу через официальный API CurseForge; остальные устанавливаются вручную со страницы мода. Обязательные зависимости не устанавливаются автоматически: их укажет проверка состава перед публикацией. Фильтры версии и загрузчика следуют подключённому серверу.

Введите название мода или откройте популярные.

Переводчик описаний

Не настроен

У описаний модов в каталоге появляется кнопка «Перевести», когда язык интерфейса русский. Перевод выполняет официальный API Яндекс Переводчика по вашему ключу; текст описания отправляется в Яндекс только после нажатия кнопки.

Как настроить переводчик?
  1. Нажмите «Создать ключ в Yandex AI Studio» выше и войдите со своим аккаунтом Яндекса. При первом входе сервис попросит создать платёжный аккаунт - действует пробный период и бесплатная квота перевода.
  2. В правом верхнем углу интерфейса AI Studio нажмите кнопку «Создать API-ключ», в открывшемся окне нажмите «Создать» (описание и срок действия можно не менять).
  3. Сразу скопируйте «Секретный ключ» (вида AQVN...) - после закрытия окна он больше не показывается. Сервисный аккаунт и права на перевод Яндекс создаст автоматически.
  4. Идентификатор каталога (folder id, начинается с b1g): откройте консоль по кнопке ниже - идентификатор показан в списке каталогов рядом с названием, а после входа в каталог виден в адресной строке (console.yandex.cloud/folders/b1g...).
  5. Вставьте секретный ключ и идентификатор каталога в поля выше и нажмите «Сохранить переводчик».

Подойдёт и ключ, созданный по старой схеме: сервисный аккаунт с ролью ai.translate.user и его API-ключ. Если в будущих версиях WebView2 заработает встроенный переводчик Chromium, приложение использует его автоматически и без ключа.

Что видно в списке?

Отдельные ключи доступа приложений, не физическая проверка компьютеров. «Активен» означает запрос за последние 90 секунд. Название задаёт сам администратор. Обновить синхронизаторы?

Будут подготовлены агенты из этой версии UDMC Control для подключённого сервера. Версия игры и загрузчик не меняются. Ключи и настройки сохранятся.

Серверный JAR заменится после остановки процесса с резервной копией. Клиентский JAR станет доступен для скачивания сразу; установленные агенты получат его при следующем запуске игры и попросят перезапуск.

Сразу после подготовки откроется окно перезапуска: там можно выбрать отсрочку, чтобы игроки увидели отсчёт в чате.
