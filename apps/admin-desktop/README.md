# UDMC Control

Windows-приложение администратора UDMC Sync на Tauri 2.

```powershell
npm run admin:dev
npm run admin:build
```

Интерфейс подключается к API серверного агента, показывает статистику, управляет сборкой и выполняет команды. Нативная часть содержит дополнительный TCP RCON-клиент. Приложение не ищет Minecraft, не изменяет локальную папку игры и не является лаунчером.

Основная документация: [../../README.md](../../README.md).
