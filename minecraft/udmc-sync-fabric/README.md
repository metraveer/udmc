# UDMC Sync Agent

Исходники Fabric-агентов. UDMC Control включает проверенные шаблоны и формирует два готовых JAR: серверный с секретами проекта и клиентский только с публичными настройками.

```powershell
./gradlew.bat build
```

Артефакт создаётся в `build/<minecraft>/libs/udmc-sync-fabric-<minecraft>-<version>.jar`. Это шаблон для разработчика, не настроенный JAR для раздачи игрокам. `npm run minecraft:build` из корня собирает все три варианта каталога и подготавливает шаблоны для Control.

На сервере агент также предоставляет статистику, консоль команд и управляемую остановку для UDMC Control. Версии Minecraft и Fabric Loader определяются автоматически.

С 0.2.2 серверный агент ведёт реестр административных устройств и приглашений. Не передавайте серверный JAR второму администратору: используйте приглашение с подтверждением владельцем. [Доступ](../../docs/administrators.md).
